# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone, regardless of experience level, identity, background, or technical viewpoint. We welcome good-faith disagreement about architecture and security, but expect discussions to remain evidence-based and professional.

## Expected Behavior

Contributors are expected to use welcoming language, respect differing viewpoints, accept constructive feedback, focus on what is best for the community and its users, and raise safety concerns responsibly. Security claims should be backed by tests, documentation, or a clearly marked limitation.

## Unacceptable Behavior

Harassment, intimidation, personal attacks, discriminatory language, publishing private information without permission, disruptive conduct, or instructions intended to facilitate unauthorized access are not acceptable. Do not use project spaces to solicit or coordinate activity against systems without explicit authorization.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may remove comments, commits, issues, or pull requests; temporarily restrict participation; or permanently ban contributors whose behavior violates this code. Reports should be made privately through the repository owner’s verified GitHub contact channel. Do not publish sensitive personal information or security-report details in a public report.
